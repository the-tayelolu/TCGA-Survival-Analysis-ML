# TCGA Survival Analysis & Machine Learning Pipeline

## 🔬 Project Overview
An end-to-end bioinformatics and machine learning pipeline developed to analyze TCGA genomic mutation profiles and clinical endpoints. This project evaluates predictive modeling strategies to classify patient survival outcomes, integrating multi-omics data structures with rigorous model validation.

---

## 📊 Key Performance Metrics
Our optimized model architecture achieved exceptional predictive performance on benchmark datasets:
* **Algorithm:** Random Forest Classifier
* **Accuracy:** 95.6%
* **Area Under Curve (AUC):** 0.954

---

## 🗂️ Repository Structure
* `TCGA_Survival_Analysis.ows`: The core Orange Data Mining workflow pipeline containing data preprocessing, feature selection, and comparative modeling blocks.
* `TCGA_Model_Predictions.csv`: Benchmark output data containing model predictions and evaluation outputs.
* `TCGA_Survival_Analysis_Report.pdf`: Comprehensive analytical report detailing exploratory data analysis, feature importance, and performance evaluations.

---

## ⚙️ Tools & Frameworks
* **Orange Data Mining:** Visual programming workflow environment for machine learning pipelines.
* **Scikit-Learn / Python Ecosystem:** Underlying algorithmic structures.
* **TCGA / cBioPortal Datasets:** Genomic mutation profiling (including *TP53*, *PTEN*, *MIR21*) and clinical metadata.
